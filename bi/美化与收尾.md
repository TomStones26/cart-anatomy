## 第二步 · 修 6 处硬错误（比配色重要）

这些是截图里看出来的实际问题，不改会影响结论的正确性。

### ① 散点图的轴被聚合成"总和"（最严重）

**症状**：散点图标题是 `frequency 的总和 和 recency 的总和`，点被压成 8 根竖条。

**原因**：`rfm_full[frequency]` 和 `[recency]` 被当数值字段拖进去，Power BI 默认给它们做了"求和"聚合——4,472 个点被压成 8 个（frequency 只有 1~8 这几个值）。

**改完报错「删除值以显示 x 轴和 y 轴对」怎么办**

这是散点图的桶配置冲突，不是数据问题。Power BI 的散点图有一条硬规则：

> **「值」桶为空 → 每个明细行画一个点**（X/Y 可以不汇总，这才是我们要的原生点云）
> **「值」桶不为空 → X/Y 必须设汇总**（否则它不知道一个气泡代表什么）

**先认清楚你这版的桶名**（2026-10 版散点图）：

```
值  /  X 轴  /  Y 轴  /  图例  /  大小  /  播放轴  /  工具提示
```

**没有「详细信息」这个桶**——在旧版里叫「详细信息」的那一格，新版合并成了 **「值」**。所以 `user_id` 应该放在 **「值」** 里，这正是它该在的位置。

**修法（就一步）：给 X / Y 设平均值**

| 桶 | 放什么 | 关键设置 |
| --- | --- | --- |
| 值 | `rfm_full[user_id]` | 保持不动（它就是"每一行一个点"的标识） |
| X 轴 | `rfm_full[frequency]` | **聚合方式 → 平均值** |
| Y 轴 | `rfm_full[recency]` | **聚合方式 → 平均值** |
| 图例 | `rfm_full[user_segment]` | — |
| 大小 / 播放轴 / 工具提示 | 全部留空 | — |

**为什么"平均值"不会算错**：`rfm_full` 里每个 `user_id` **只出现一次**（4,472 行 = 4,472 个用户），所以按 user_id 分组后每组只有 1 行，"平均值"就等于这个用户自己的 frequency / recency。**结果和"不汇总"完全一样**，只是换了一种说法绕过校验。

> 改完标题会从 `frequency 的和 和 recency 的和` 变成 `frequency 的平均值 和 recency 的平均值`。**但你会发现它变成了一排竖线——这不是 bug，见下。**

### ①-b 为什么改完是一排竖线（数据决定的，不是设置问题）

`frequency`（复购次数）在这份数据里**只有 9 个整数取值**：

| frequency | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 人数 | 1,192 | 1,312 | 1,016 | 551 | 265 | 94 | 26 | 14 | 2 |

**整数变量做 X 轴，散点在数学上只能落在 9 条竖线上**，这跟 Power BI 无关。任何"整数 × 连续"的散点图都会成网格。

> ⚠️ 顺带一个真问题：`frequency = 1` 有 **1,192 人（26.7%）**。如果 X 轴从 2 开始（你截图里就是这样），**这一整条 1,192 个点被裁在轴外看不见**。这是比"竖线"更值得修的。

**三个改法，按推荐度排**

| 方案 | 做法 | 效果 |
| --- | --- | --- |
| **A. 换 X 轴为金额（推荐）** | X 轴换成 `rfm_full[monetary]` → 平均值；再打开 X 轴 **对数刻度** | 真正的散点云。金额 13~78,302 跨度大且右偏（中位 4,511、均值 7,678），对数轴能把低消费区的密集点摊开 |
| B. 换图型 | 删除散点图，改用**柱状图**：X = `frequency`，Y = `分层人数` | 离散变量本来就该用柱状图，一眼看出"复购 1~2 次占 56%" |
| C. 保持现状当条带图读 | 不动 | 仍能读出"复购次数越高、最近购买间隔越短"的规律，但视觉上不讨喜 |

**方案 A 的具体设置**

| 桶 | 放什么 |
| --- | --- |
| 值 | `rfm_full[user_id]` |
| X 轴 | `rfm_full[monetary]` → **平均值**；格式 → X 轴 → 打开 **对数刻度** |
| Y 轴 | `rfm_full[recency]` → **平均值**；打开 **反转范围** |
| 图例 | `rfm_full[user_segment]` |

**读图规则（注意方向，别读反）**

- Y 轴反转后：**越靠上 = recency 越小 = 最近买过**（好）
- X 轴（金额）：**越靠右 = 花得越多**
- **右上角 = 高价值用户**（近期 + 高消费）
- **左上角 = 新客/潜力**（近期 + 低消费）
- **右下角 = 沉睡高价值**（很久没买但曾经花得多）→ 最该唤醒的一群
- **左下角 = 流失**（很久没买 + 花得少）

> 我上一条说"左下角是高价值"，说反了——那是没把反转算进去。以这张表为准。

## 第三步 · 三个提亮效果（每个 3~5 分钟，效果最明显）

### 效果 1 · 条形图做渐变（最省事的"高级感"）

以品类条形图为例：**格式 → 条形 → 颜色 → 条件格式（fx）** → 格式样式选 **渐变** → 依据 `总销售额` → 最小值 `#22314F`、最大值 `#FF6B35`。

效果：销售额越高的条越亮橙，越低的越沉。一张图立刻有层次，不用改数据。
同样的做法可以用在**城市图**（按用户数渐变）和**年龄段柱状图**。

### 效果 2 · 自定义工具提示页（专业感最强，强烈推荐）

悬停任意一根柱子，弹出一张迷你图表——这是咨询公司报表的标配。

1. 新建页 → 页信息 → **页面大小** 改为 `320 × 240` → 类型选 **工具提示**
2. 在这个小页里放：一个迷你折线图（`日期表[月]` × `总销售额`）+ 一个卡片（`有效订单数`）
3. 回到品类条形图 → **格式 → 工具提示 → 类型 = 报表页** → 页面选刚才那张
4. 悬停任意品类，就能看到该品类自己的月度趋势

> 同一招可以用在 RFM 条形图上：悬停某分层，弹出该类用户的人数、人均消费、平均 R/F。

### 效果 3 · 卡片加"引用标签"，从数字变指标

Power BI 的**新式卡片图**支持引用标签：

选中卡片 → **格式 → 引用标签 → 添加** → 输入目标值（例如总销售额目标 `50000000`），标签文字写"年度目标 5,000 万"。

效果：卡片下方多出一条细进度条，数字不再是孤立的，而是"完成了 85.7%"。单看数字变成看达成率，这是最容易被夸"专业"的改动。

## 第三步-b · 视觉对象拖不动 / 放不大怎么办

**先排除两个"拖不动"的硬原因**

| 检查 | 位置 | 如果中了 |
| --- | --- | --- |
| **锁定对象** | 视图 → 锁定对象 | 勾着就**完全拖不动也改不了大小**，取消勾选 |
| **被分组了** | 右键视觉对象 → 取消分组 | 分组后只能整体缩放，成员单独拖不动 |
| 页面缩放太小 | 视图 → 页面视图 → 实际大小 | 缩小到 50% 时手柄只有几像素，很难抓住 |

**最可靠的办法：直接输数值，不拖**

选中视觉对象 → 「格式」窗格 → **常规 → 属性 → 大小和样式**，这里有四个输入框，直接填：

| 字段 | 含义 |
| --- | --- |
| **X** | 左边距（像素） |
| **Y** | 上边距 |
| **宽度** | 像素 |
| **高度** | 像素 |

比拖拽精确，而且不会误碰相邻的图。

**页面 4 推荐布局（把表格给足宽度）**

现在的问题是表格被挤成右侧一条窄柱（约 250px），四列中文根本放不下。改成这个：

| 图 | X | Y | 宽度 | 高度 |
| --- | ---: | ---: | ---: | ---: |
| 品类条形图 | 16 | 72 | 620 | 300 |
| **品类明细表** | **650** | **72** | **600** | **300** |
| 漏斗图 | 16 | 384 | 1236 | 320 |

表格 600px 宽放 4 列（品类 / 商品数 / 有效转化率 …）绰绰有余；漏斗占满底部整行，视觉更稳。

> 如果坚持要表格更宽，就把它移到最下面一行：X=16, Y=364, 宽度=1236, 高度=340，漏斗挪到上方右侧。但那样漏斗会被压扁，不如上表均衡。

**表格内容太挤的另外三招**

1. **缩小字号**：格式 → 列标题 / 值 → 文字大小 8
2. **减少列**：只留「品类 / 商品数 / 有效转化率」三列，其余看图表
3. **列宽自动**：格式 → 列标题 → 自动调整列宽
